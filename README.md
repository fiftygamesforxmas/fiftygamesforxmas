Quick start:

Step:
- Setup Python

- Clone this repository:

	git clone https://github.com/fiftygamesforxmas/fiftygamesforxmas/

- if on Mac or Linux go to the root dirctory and

	chmod 777 go.sh

- run go.sh (MAC or Linux) or go.bat (Windows)

	./go.sh
or
	go.bat

The program will audit all the python games in this repository

It will create virtual environments in its home directory for each program (they all share the same directories)

After that you should see the Launcher window, with icons.  You can switch to a less intuitive directory view, if you choose.

The icons can be sorted by most launched or name.

Double click the icons to run the game or utility.

Enjoy!
